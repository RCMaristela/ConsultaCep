# Consulta de CEP

Site que busca o endereço a partir de um CEP usando a API pública ViaCEP e mostra uma foto da cidade vinda do Wikimedia Commons. Visual inspirado em correio aéreo.

**Demo:** https://rcmaristela.github.io/consulta-cep/

![Resultado da busca](docs/cep-resultado.png)

## Tecnologias
HTML, CSS e JavaScript (sem frameworks) · API ViaCEP · Wikimedia Commons
